## 《序》

书名《霸道女皇爱上我》非常“中二”，因为起初是为了编排一个朋友。

我有个朋友叫张秋山，为人比较“泰迪”。因此，群里形成一个独特爱好：编排他。

每当有通奸者被抓、被暴打、被杀、坠楼，我们都会艾特他。我给他写各种各样的段子，夸他“潘驴邓小闲”，主要是驴。比如在一本奇幻故事里把他写成驴精，自此，“马户”就是他的专属名。后来又把他写成武媚娘的面首，写成“马户将军”，照着小黄文写的。

然后，我看网文穿越界还没有写武媚娘面首的风气，感觉这是个处女地，就持续扩展，遂成此书。没错，编排人编排成了一本书。

如有亲朋好友看到这本书，我一定得双手捂脸，辩解道：半黄色内容只是调侃，并不能反映本人的价值观、性取向、爱好与追求。那是为了吸引某些读者，不是为你们准备的。

书中对于历史的考据非常详实，对历史人物、事件的讲述与评价尽量客观公正，地理描述相当精准，故事与人物性格高度匹配。并且，我一如既往的厌恶抄袭，几乎每个局部都试图写出新意。这才是你们熟悉的那个我：特正经、苛求完美且充沛着旺盛的创造欲。

故事里，整个大唐民族压抑至深的力量喷薄而出，每个领域都有英雄纵横驰骋。主角张秋山是“触发者”，他触发了一切，却不能主宰一切，即“张秋山搭台，众豪杰唱戏”。因此，张秋山死后，故事还会持续很久。



后来，我听说一个网文风气：反“虐主”。就是各类网文追求极致快餐化，主角从来就一帆风顺，一丁点坎坷都不能有，给主角设置障碍就是虐主。然而，本文就是为了编排主角而生，不虐主还有灵魂吗？所以，看本文就是看花式虐主的。

此外，我必须特别鄙视一种写法：带“系统”。我读过大量小说和网文，也包括我并不怎么喜欢的言情、女频等，但我最看不下去的就是“系统”类。有了“系统”，那就不需要思考合理性、不需要谨慎安排情节、不需要斟酌人物行为、不必查阅大量资料、不需要展现角色的智慧与才华。“系统”类小说就像是大锅里扔进去臭鱼烂骨头碎菜叶子，再加上巨量调料遮味儿，随便搅合几下就端上桌，看一眼都恶心。

用“系统”创作廉价无脑文化产品的写手们，我鄙视你们所有人！

我没心情为了上架过审而改来改去。因此，本书准备长期免费。

## 《简介·剧透·致歉》

矮矬穷理工学霸张秋山穿越成武则天的面首薛怀义，不仅魁梧英俊，而且具有一根堪比大牲口的东西。他试图反抗自己的命运，但还是被迫成为女皇的面首。出于戏谑，他被封为“马户将军”。

借着夜夜侍奉女皇的机会，他不停的吹枕边风，对唐朝进行了大刀阔斧的改革。因他天性善良，从酷吏手下拯救了无数人。他是唯一的“一人之上、万人之上”的大臣。

张秋山心中萦绕不去的难题是：怎样让华夏文明跳出治乱兴衰三百年的怪圈？

借着解决北部边患问题，他开始实验一种新的解决方案：将边疆地区切割成小邦，并且强力推行贵族共和制和任期制，严禁长期连任，严禁家族继承，防范小邦中出现军头。

照此思路，辽宁地区建了六个邦，朝鲜半岛建了九个邦，日本建了十个邦，琉球建一个邦，台湾建两个邦。后期，西北、云贵、越南、南洋都建立大量的邦国，数以百计。



同时，一群大唐流民来到图门江口-海森崴地区，建立了图门邦。此处是极寒苦之地，人迹罕至，且地图缺失，故此没有给他们划定北部边界，只划定 42° 纬线为南部边界。因为没有贵族，所以他们实施议会制。

因为太过穷困，他们积极充当佣兵，创下“图门佣兵”的赫赫威名。他们协助大唐扫平叛乱，暴揍不服从的其余小邦，被称作“大唐之槊”。他们英雄辈出，不断向北、向西扩展疆域，最终成为第一强邦。图门的人口相当于大唐的五分之一，面积甚至超过大唐。

武则天死后，张秋山在权力斗争中失败，流亡图门邦，李隆基成为皇帝。之后，大唐与图门的关系迅速恶化，两大强国磨刀霍霍，大战一触即发。



【漫长的故事线】本小说故事线长达 75 年。所以，主角张秋山掌握大权并不意味着故事结束，后面还有很多。作为参考，三国演义的故事线长 111 年。

【时间线】故事中用**武则天出生当做时间原点**。圣诞 58 就是武则天 58 岁，圣诞 64 就是 64 岁，圣诞 133 时媚娘早就死了，但纪年方式不变。

【真·虚】如果你好奇一个人物是真实还是虚构，可以去查人物表。名字后面带“真”的，就是真实的。哪怕只有历史记载中一笔带过的人名，也归入真实存在。带“虚”的，就是完全虚构的。

真实人物的生卒与籍贯尽量符合历史，有时候也根据情节有所改动。

后来有读者反馈：看见【虚】太出戏。我觉得有道理，从此虚构人物不再标明。如果你看到了【虚】那就是没删干净。

【图片】本人制作的版本包含大量图片。如果忽略地理因素，往往不能清晰理解历史，更有许多信息，是文字难以传达的。只希望诸君阅读时，能更好的享受历史。

【致歉】截至 2025-11-20，本书零零碎碎写了 30 万字。但连缀完整的，也就 10 万字左右。造成这种情况的原因是……我写故事靠灵感，喜欢跳着写。我想出一个好故事，才会把这段写完。以后我努力把故事讲完整。

# 《楔子·宇宙的尽头》

“9527，宇宙的命运就由你掌握了！”大统领的三维激光投影依然挺拔，声音依然坚定。

宇宙尽头的时空奇点中，张秋山蜷缩在狭小的维生囊里，狐疑道：“我们是不是过度担忧了？科技爆炸才几百年，就开始畏惧宇宙的热寂？”

大统领似乎没听到他的问题，继续说：“根据我们的计算，必须提前一千年以上进行干预，才能有效避免宇宙热寂。我们来得太晚了，只能借助你的穿越，来挽救整个宇宙！毫无疑问，你就是宇宙拯救者……”

“宇宙寿命有一百多亿年，热寂至少是千亿年之后，差这一千年吗？”张秋山问。

“你游戏还是打少了，开局滚雪球很重要的。宇宙奇点的开启可能只有这一次，而你的穿越目标正是煌煌大唐……”

“让我突击几个月唐史，就为这个啊？”

“可不呢？正经人谁学唐史啊？”大统领接着说：“你要加快那个时间线的科技进度，让人类提前一千年科技爆炸，有能力干预热寂……”



张秋山有了些信心：“只要穿越理论没问题……大哥你是了解我的。”

“怎么？”

“咱可是一路数理化小天才混出来的，待我给他们传授一番，分分钟让大唐科技飞升……”

“不可、不可！”大统领脸色大变。

“咋啦？”

“绝对不能让‘你是穿越者’成为所有人的共识，那就会触发‘观察者效应’，后果难料……”

“什么鬼？……究竟会怎么样？”

“不知道，但是有一些很可怕的推论。”

“……有多可怕？”

“最严重的情况下，可能会导致两个宇宙的波函数坍缩。也就是突然毁灭两个宇宙……”大统领危言耸听。

“也有可能毫无影响，对吧？”张秋山翻着白眼。

“的确可能如此，但我们不敢冒险……”大统领继续吓唬他：“还有中等风险，也就两个宇宙的信息流波函数坍缩，换句话说就是‘你的意识灰飞烟灭’，其余不受影响。我个人认为这种理论几率最高……”

“信息流？两个宇宙只能交换信息不能交换物质对吗？也就是说，只能魂穿、不能肉穿？”张秋山对穿越届很有了解。

“根据目前的理论，确实如此。”大统领面色尴尬。

“你们这些个搞量子物理的货色能有点儿准话吗？你这么搞凭空增加很多难度呀！”

“天将降大任于斯人也……”

“打住、打住，”张秋山的眼珠子快翻到脑仁儿里了：“咱这个学历不适合低端激励手法。”



“咳咳……”大统领清了清嗓子，道：“这次穿越，涉及到大量科学前沿且难以验证技术。”

“别废话了，我想问：为什么是我？”

“你是咱们所有人里面最有才能的……”

“忒假！你丫嘴里能不能有点儿实话？”

“你最瘦小，穿越仓只能容纳你的体型……”

“TMD，你接着编！”

大统领叹了口气，徐徐道：“你矮丑穷、孤儿院长大、废宅、没有女朋友、没有亲人，无牵无挂。我们拖家带口的……”

“……”

“从现实角度出发：可能，我是说‘可能’，思念你的人越多，越容易触发观察者效应……”

“你唯心了你知道吗？你不是整天号称自己是坚定的唯物主义战士吗？”张秋山咆哮着。

“都是概率问题啦，说不清的。”大统领一摊手，装出满脸无奈。

“你说的这个概率，大约有多少。”

“也就 T3 分之一啦，根据……”

张秋山打断他：“等一下，这个 T 代表什么？”

“Tree(3)……”

“艹……”张秋山无力吐槽：“你们要不要脸？这个 Tree(3) 怎么算出来的？咱都是内行，别糊弄哈。”

“论文有点长，你慢慢看，已经传给你了。”

“我瞅瞅……一千三百七十八，万页！你是凯丁吗？”张秋山有些癫狂了。

“早就说了，论证过程很复杂的嘛，我们采纳了多种思路……”



“穿越之后，怎么获得补给？”

“……没有。”

“情报支持总要有的吧？”

“时空门开启一瞬间就中断了，我们真没办法与你通信。”

“你是不是想让我心甘情愿的当小白鼠？”张秋山怒不可遏。

“首先，时空门的开启非常难得，根本就不可控。再者，这次的穿越目标棒极了，有帝王般的待遇。”大统领开始诱惑他：“一代女皇武则天晓得吧，哎呦，年轻时好漂亮的，而且是波涛汹涌……根据太阳系量子集群的演算，这次穿越目标就在武则天附近，正值盛唐，你运气很棒的。”



“武则天附近，帝王待遇，不会就是武则天本人吧？亦或是太平公主？”张秋山不惮以最大的恶意揣度大统领：“喂，那个时代做女人很难发挥的，难度忒大了。”

“放心，我们肯定保住你的小老弟。帝王般的待遇哟——”大统领拖着长腔。

“让我做李世民吗？”张秋山突然有了期待：“虽然开国难度很大，但真的好爽啊！”

“抱歉，不是李世民。开国难度实在太大，怕你搞不定……”大统领否定道。

“是李治？”张秋山想：唐高宗的痛苦来自于早早中风，半辈子病病歪歪，所以必须注重身体健康，减少低密度胆固醇摄入……

“也不是李治。”大统领继续否定，但抛出一个诱惑：“然而，你是他俩的同道中人。”

“同道中人？……李贤？李显？李旦？”张秋山继续猜测。这三兄弟一辈子活在亲妈武媚娘的阴影中，让他去玩宫心计吗？

“也不是他们。”大统领还是否定，但他斟酌用词：“某种意义上说，他们也是你的同道中人。”

“不会是李隆基吧？”张秋山开始憧憬：穿越成李隆基那就更好了，接手一个完整的大唐帝国，身体好、寿命长，还有机会跟杨贵妃嘿嘿嘿……

“说基不说吧，文明你我他……也不是李隆基。”大统领似乎有点歉疚：“某种角度说，广义上你也是他的同道中人……”话没说完，通讯突然断了，大统领的投影消失在空气中。

“说清楚，什么同道中人？”时空里回荡着张秋山焦急的呼唤：“喂，把话说完呀，究竟是什么同道中人啊？！！！”
